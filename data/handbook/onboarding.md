# New Employee Onboarding (fictional)

This handbook is fictional and exists only to demonstrate and evaluate the retrieval system.

## First week
New employees receive their laptop on the first day. The IT helpdesk configures the laptop and enrolls it in device management. Employees must set up two-factor authentication before they can access any internal system.

## Accounts and access
Access to the code repository is requested through the access portal. Production access is not granted during the first 30 days. The rules for requesting and approving access are described in the access management policy.

## Buddy program
Every new employee is paired with a buddy from the same team. The buddy answers day-to-day questions, introduces the employee to the team rituals, and joins the first code review. The buddy relationship lasts for the first three months.

## Mandatory trainings
During the first two weeks, new employees complete the security awareness training and the data protection training. Both trainings must be passed with at least 80 percent before the end of the second week.
